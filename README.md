# Carbon Tracker Group Project - Group 19
## Overview
_Carbon tracker proof of concept web app._

This web app gives households the ability to record their household activities that contribute towards carbon emissions, in order to track and visualise their carbon footprint. We provide users with a central dashboard page for their graphs and statistics, as well as a recommendation system that gives emission reduction suggestions depending on the household's logged activities and total carbon footprint values. The system uses official emission formulae to correctly calculate the user’s carbon footprint.

## Project information
This project was written using **HTML** and **PHP** (sqlite3), with support from **javascript** for interactivity and most notably for usage of **Chart.js** (_https://www.chartjs.org/_).
